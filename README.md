\# Football Player Finder



\## Deskripsi Proyek

Football Player Finder adalah proyek Sistem Temu Kembali Informasi (STKI) yang bertujuan membantu pengguna mencari dan menemukan informasi pemain sepak bola berdasarkan kriteria tertentu.



Proyek ini dikembangkan menggunakan Python dan direncanakan memiliki antarmuka web yang sederhana agar mudah digunakan.



\## Tujuan

\- Mempermudah pencarian informasi pemain sepak bola.

\- Menerapkan konsep Sistem Temu Kembali Informasi.

\- Mengembangkan aplikasi pencarian berbasis data dengan antarmuka web.



\## Dataset

Dataset pemain sepak bola disimpan secara lokal di folder `dataset/` dengan nama `player\_profiles.csv`.



Dataset mentah tidak disertakan dalam repositori GitHub. Informasi sumber, struktur, dan atribut dataset akan didokumentasikan setelah pemeriksaan data dilakukan.



\## Rencana Pengembangan

1\. Memeriksa struktur dan kualitas dataset.

2\. Melakukan pembersihan dan persiapan data.

3\. Mengembangkan fitur pencarian dan penyaringan pemain.

4\. Mengevaluasi hasil pencarian.

5\. Membuat antarmuka web menggunakan Streamlit.

6\. Menyusun dokumentasi dan hasil pengujian.



\## Teknologi

\- Python

\- Jupyter Notebook

\- Pandas

\- Streamlit (direncanakan)
